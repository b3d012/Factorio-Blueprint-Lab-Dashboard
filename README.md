# Factorio Blueprint Lab V2

A fresh foundation for the dashboard-first rebuild of Factorio Blueprint Lab.

## Stack

- React
- Vite
- TypeScript

## Local development

```bash
npm install
npm run dev
```

## Notes

- The dashboard uses a curated Kirk McDonald data subset as its first domain layer.
- The sprite helper is wired to Kirk's public sprite atlas so the UI can show real Factorio-style icons.
- Phase 1 focuses on the dashboard and domain foundation, not a full calculator port.
